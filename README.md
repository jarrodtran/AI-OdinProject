# The AI Odin Project

A free, open-source **AI Product Management** learning platform modeled after The Odin Project.

**Live App:** [https://ai-odin-project.vercel.app](https://ai-odin-project.vercel.app)

## What's Inside
- **3 Structured Learning Paths · 15 Courses · 36 Modules** (*Foundations*, *AI Product Strategy & Growth*, and *Technical AI PM*)
- **10 Interactive Browser Simulators** (Token Economics, Prompt Spec Sandbox, Eval Studio, Hybrid RAG Debugger, Agent Reliability, AI-Native PRD Studio, Multimodal & Voice Latency, Incident War-Room, Cascade Model Router, and AI Pricing & Margin Stress-Tester)
- **AI PM Field Manual & Playbook (`/playbook`)** featuring **10 Markdown Templates**, **6 Decision Matrices**, **6 AI-Native Product Teardowns** (Cursor, Perplexity, NotebookLM, Sierra/Fin, Linear Triage, Harvey/Hebbia), **16 Staff Interview Blueprints**, and **45 Technical Glossary Entries**
- **Guest-First Cloud Progress Sync (`/api/progress`)** supporting Email + scrypt Passcode accounts, GitHub/Google learner profiles, cross-device `ODIN-XXXX-XXXX` recovery keys, 7-pillar competency radar, and Markdown Portfolio Dossier export

## Local Development

```bash
npm install
npm run dev
```

Or run directly with Node if `/usr/bin/env` is restricted in your shell:

```bash
node ./node_modules/next/dist/bin/next dev -p 3000
```
